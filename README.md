## Frequently Asked Questions

### Is this tool compatible with Windows 11?

Yes. The Runway ML Complete Suite 2026 is fully compatible with both Windows 10 (build 1903 and above) and all editions of Windows 11.

### What graphics card do I need?

A dedicated GPU with at least 6 GB of VRAM is recommended for optimal performance. NVIDIA GTX 1060 or AMD RX 580 are the minimum. For faster generation times, NVIDIA RTX 3060 or higher is ideal.

### Can I use the suite without an internet connection?

The application requires an internet connection during initial setup to download AI models. After installation, basic image editing features work offline, but video generation and model updates require connectivity.

### The installer is flagged by my antivirus. What should I do?

Some antivirus tools may produce false-positive warnings with AI software. You can safely add **SetupLatest.exe** to your antivirus exclusion list before running it.

### How do I update to the latest version?

The suite includes an automatic update checker. When a new version is available, you will receive a notification upon launch. You can also manually check via the **Help > Check for Updates** menu.
